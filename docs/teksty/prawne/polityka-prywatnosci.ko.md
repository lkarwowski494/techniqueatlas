## 요약

Technique Atlas 웹사이트 자체는 개인정보를 수집하지 않습니다. 계정, 입력 양식, 광고가 없습니다. 쿠키, 브라우저 저장소, 분석 도구, 추적 도구를 사용하지 않습니다.
웹사이트는 자체 파일만 불러옵니다. 검색과 필터는 사용자의 브라우저에서 작동합니다.
웹사이트는 호스팅 서비스를 통해 제공되며, 이 서비스는 보안을 위해 방문할 때마다 IP 주소를 로그에 기록합니다(자세한 내용은 아래 참조).
문의: {{kontakt}}.

## 웹사이트 운영자

웹사이트 운영자는 {{administrator}}이며, 연락처는 {{kontakt}}입니다.

## 웹사이트를 열면 일어나는 일

- 브라우저가 호스팅 서버에서 웹사이트 파일(HTML, CSS, 스크립트, 종목 그림)을 내려받습니다. 웹사이트는 다른 서비스에서 글꼴, 스크립트, 이미지, 플러그인 등 아무것도 불러오지 않습니다.
- 호스팅 서버는 방문할 때마다 IP 주소를 기록하고 보안을 위해 보관합니다. 로그는 미국에 본사를 둔 호스팅 제공업체가 자체 규정에 따라 관리합니다. 따라서 데이터가 미국에서 처리될 수 있습니다. 제공업체는 EU-미국 데이터 프라이버시 프레임워크(유럽연합 집행위원회의 적정성 결정)를 준수한다고 밝히고 있습니다.
- 웹사이트에는 자체 방문 통계가 없습니다.

## 검색, 필터, 그림

- 종목 이름 검색창에 입력한 텍스트는 어디로도 전송되지 않습니다. 브라우저가 웹사이트 서버에서 해당 언어의 이름 목록 파일 하나를 내려받아 사용자의 기기에서 검색합니다.
- 목록 필터는 브라우저에서 작동하며 페이지 주소를 바꾸지 않습니다.
- 종목의 애니메이션 그림은 웹사이트 자체 데이터 파일을 불러옵니다. 시스템에서 '동작 줄이기' 설정이 켜져 있으면 애니메이션이 자동으로 시작되지 않습니다. 이 설정은 사용자의 브라우저만 읽습니다.
- 웹사이트는 JavaScript 없이도 작동합니다. 종목 목록과 설명은 일반 HTML로 되어 있습니다.

## 다른 서비스로 연결되는 링크

- 'App Store' 버튼은 App Store의 앱 페이지로 연결됩니다. 주소에는 캠페인 태그 `techniqueatlas-<언어>`가 포함됩니다. 이 태그는 웹사이트의 어느 언어 버전에서 이동했는지만 나타내며, 사용자가 누구인지는 나타내지 않습니다. 이동한 후에는 앱 스토어의 규정이 적용됩니다.
- iPhone과 iPad에서는 브라우저가 앱 배너를 표시할 수 있습니다. 이 배너는 페이지 코드의 태그를 바탕으로 브라우저가 직접 표시합니다.
- 언어 전환 버튼과 그 밖의 링크는 이 웹사이트의 페이지로 연결됩니다.

## 문의하실 때

웹사이트에는 문의 양식이 없습니다. {{kontakt}}(으)로 이메일을 보내시면, 앱 개인정보 처리방침의 '문의하실 때' 항목에 설명된 대로 메시지를 처리합니다: {{politykaAplikacji}}. 해당 항목에는 목적, 법적 근거, 보관 기간, 수신자, 사용자의 권리가 나와 있습니다.

## 사용자의 권리

사용자는 자신의 데이터에 대한 열람, 정정, 삭제, 처리 제한, 처리 반대, 이동의 권리가 있습니다. 또한 폴란드 개인정보보호청장에게 이의를 제기할 수 있습니다.
웹사이트 자체는 개인정보를 수집하지 않으므로, 사용자가 보낸 이메일을 제외하면 제공하거나 삭제할 수 있는 데이터가 없습니다. 호스팅 로그에 관해서는 저희에게 연락하시면 제공업체와 연락 방법을 알려 드립니다.

## 데이터를 제공해야 하나요?

아니요. 웹사이트를 이용하는 데 어떤 데이터도 제공하지 않습니다.

## 자동화된 결정

프로파일링을 포함해, 오로지 자동화된 처리에만 근거한 결정을 내리지 않습니다.

## 아동

웹사이트 자체는 아동을 포함해 누구에게서도 데이터를 수집하지 않습니다.

## 변경

웹사이트가 데이터를 다루는 방식이 바뀌면, 해당 버전을 공개하기 전에 이 방침을 변경하고 새 날짜를 표시합니다. 웹사이트 코드는 공개되어 있으므로 모든 변경 사항은 저장소 기록에서 확인할 수 있습니다.
