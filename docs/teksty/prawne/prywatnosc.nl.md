# Privacy

De website Technique Atlas verzamelt niets over jou. Er zijn geen accounts, formulieren, cookies, advertenties of analytics, en de zoekfunctie en filters werken alleen in je browser.

De website wordt aangeboden via GitHub Pages. Zoals elke hostingdienst slaat GitHub Pages bij een bezoek technische logs op, waaronder je IP-adres, volgens eigen voorwaarden.

De website wordt beheerd door Apps4Brew, Warschau. Vragen: support@apps4brew.com.
