O site Technique Atlas não recolhe nada sobre si. Não tem contas, formulários, cookies, anúncios nem ferramentas de análise, e a pesquisa e os filtros funcionam apenas no seu navegador.

O site é disponibilizado pelo GitHub Pages. Como qualquer serviço de alojamento, este guarda registos técnicos das visitas, incluindo, entre outros, o endereço IP, segundo as suas próprias regras.

O site é gerido pela Apps4Brew, Varsóvia. Questões: support@apps4brew.com.
