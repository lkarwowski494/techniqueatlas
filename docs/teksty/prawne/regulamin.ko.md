## 1. 서비스 제공자

웹사이트 {{adresStrony}}의 운영자는 {{administrator}}이며, 연락처는 {{kontakt}}입니다(이하 '저희').

## 2. 웹사이트에서 제공하는 것

무료로, 가입 없이 다음을 제공합니다.
- 설명과 근육 정보가 담긴 종목 라이브러리. 대부분의 종목에는 자세 팁, 흔한 실수, 대체 종목, 동작 그림도 포함됩니다.
- 필터가 있는 종목 목록과 이름 검색
- 여러 언어로 된 웹사이트 버전

웹사이트의 콘텐츠는 정보 제공용입니다. **의학적 조언이나 개인별 치료 또는 재활 계획이 아닙니다.** 질병이나 부상이 있거나, 임신 중이거나, 건강 상태가 걱정된다면 운동에 대해 의사나 물리치료사와 상담하세요.

## 3. 기술 요구 사항

인터넷에 연결된 최신 웹 브라우저만 있으면 됩니다. 설명과 종목 목록은 JavaScript 없이도 작동합니다. 그림 애니메이션, 필터, 검색은 JavaScript를 켜야 작동합니다.
웹사이트는 계정이나 쿠키가 필요 없으며, 아무것도 설치할 필요가 없습니다.

## 4. 이용 규칙

- 웹사이트에는 자신의 콘텐츠를 게시할 수 없으므로 관리할 사용자 콘텐츠가 없습니다. 저희에게 연락할 때 불법적인 내용을 보내지 마세요.
- 콘텐츠는 콘텐츠 라이선스({{adresStrony}}/…/licencja)에 따라 이용합니다. 라이선스 범위를 넘어 콘텐츠의 상당 부분을 대량으로 내려받거나 자동으로 복사하는 행위는 금지됩니다.

## 5. 이용의 시작과 종료

이용은 웹사이트를 여는 순간 시작되고 닫는 순간 종료됩니다. 기간이 정해진 계약이나 요금은 없습니다.

## 6. 불만 접수

웹사이트에 관한 의견과 불만(예: 콘텐츠 오류, 작동하지 않는 기능)은 {{kontakt}}(으)로 보내 주세요. 어떤 문제인지, 어느 페이지에 관한 것인지 적어 주세요. 부당한 지체 없이, 늦어도 14일 이내에 답변드립니다.

## 7. 책임

저희는 콘텐츠가 정확하도록 주의를 기울이지만, 오류가 없다거나 웹사이트가 중단 없이 작동한다고 보장하지 않습니다. 운동은 본인의 책임하에 하며, 자신의 능력에 맞게 무게를 정하세요.
