## Pangkalan data senaman

Tanpa kebenaran bertulis daripada kami, anda tidak boleh memuat turun atau berkongsi keseluruhan atau bahagian yang substansial daripada pangkalan data senaman, termasuk dalam bentuk yang telah diubah, termasuk untuk membina aplikasi lain, pangkalan data atau set data untuk melatih model. Ini juga terpakai kepada muat turun berulang bahagian-bahagian kecil jika secara keseluruhannya membentuk bahagian yang substansial.
